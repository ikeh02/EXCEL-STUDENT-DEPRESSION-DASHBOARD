# 📊 Students Depression Insight Dashboard (Excel 2016)

## 📌 Executive Summary
This project features an interactive, executive-grade dashboard built in Excel 2016 analyzing a dataset of **4,464 student records**. The dashboard investigates key drivers of student mental health across four analytical angles, helping identify high-risk groups and protective lifestyle buffers.

## 🎯 Key Analytical Angles

1. **Angle 1: Academic Impact (Semester Trend)** — Tracking depression rates across academic progress (Semesters 0–13).
2. **Angle 2: Social & Lifestyle Factors** — Evaluating mental health outcomes based on living arrangements, class tier, and social support.
3. **Angle 3: Demographics & Financial Pressure** — Analyzing depression prevalence across financial stress tiers and demographic categories.
4. **Angle 4: Health Condition Correlation** — Mapping historical health conditions to overall risk profiles.

---

## 🛠️ Technical Features & Architecture
* **Global Interactive Slicers:** Connected across all Pivot Tables via **Report Connections** to dynamically filter all 4 charts simultaneously (e.g., Gender, Home Division, Relationship Status).
* **KPI Header Cards:** Displays baseline metrics: *Total Students (4,464)*, *Baseline Depression Rate (27%)*, *Highest Risk Tier*, and *Strongest Buffer Group*.
* **Custom Visual Hierarchy:** Built with an executive dark navy banner (`#16356D`), light grey-blue backdrop (`#CEDCEA`), and padded card containers (`#E8E8E7`).
* **Macro-Enabled File (.xlsm):** Configured to support interactive Excel features while preserving calculated layout fields.
